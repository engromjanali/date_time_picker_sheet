# date_time_picker_sheet example

A gallery for trying every option of the package. It has switches for the presentation (sheet, dialog or auto), single
or range mode, start now, allow past, today only, the Now action, 24-hour time, the minute step, an async validator,
dark theme and right to left. Pick a time and the result is shown under the button.

```bash
flutter run               # on a connected device or emulator
flutter run -d chrome     # in the browser
```
